# Canon — the context layer's timeless tier

"Our understanding of the game" (see `../docs/canon.md`). Each entry is built
**data-first** (Phases 1–4: data → blind themes → narrative → reconcile) and
written in a football-person register, not academic. Holistic World-Cup eras are
the spine; team studies double-click on top.

**House style (per direction):** *data-driven and told through the players.* Cite
the numbers, name the names — an era written without people is the outsider trap.
(e.g. Fontaine's 13 vs Schillaci's 6; Argentina's 5 goals to a final.)

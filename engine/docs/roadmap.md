# Roadmap — the phases of this project

What "the loop" actually requires, in order, with honest blockers.

## Phase 0 — Design & method proof ✅ DONE
Charter, architecture, belief schema, eras, analysis model, data-reach audit,
content/delivery spec, landscape. **The four-phase method proven end-to-end** (the
*Defensive Era* Canon entry, built data → blind → narrative → reconcile). Register
calibrated (data-driven, told through the players).
→ The "can this work / does it understand the game?" question is answered **yes**,
at coarse resolution.

## Phase 1 — The Canon (the understanding asset) — *autonomous, unblocked*
Build "our understanding of the game": the holistic **World Cup era spine**
(coarse, 1930→now), the recent **fine eras** (2018–24 control era), and **team
double-clicks** (tiki-taka Barça as a team study, etc.). Each entry data-first,
four phases, in the locked voice; you review drafts.
**Blocker:** none. Can run now.

## Phase 2 — The live pipeline (loop machinery) — *scaffold now, runs on a key*
Data ingestion (API-Football), the analysis tasks (pre-game · game-day ·
post-game · MOTM · player-scores · round-insights), the **transparent
player-rating model**, content rendering (formation/pitch graphics, cards), the
FIFA EFI parser. The belief engine forms & tests beliefs per match. Drafts route
to you.
**Blocker:** an **API-Football key** to pull live data (scaffolding can start
without it).

## Phase 3 — Publish & go autonomous (close the loop) — *needs your accounts*
X / Instagram accounts + keys, the **publish gate** (your approval), and the
**scheduling/triggers** (the proactive pre/post/round clock). Then the loop runs:
data → belief → content → your review → publish → learn.
**Blocker:** social accounts + keys (and an optional analytics endpoint).

## Phase 4 — Compounding (the actual point) — *ongoing*
It runs live (**WC 2026 first**): the Canon and the beliefs grow each match,
content ships, the system gets smarter, you learn football and have fun — and we
find out whether AI genuinely has a role. Forward era-mining accumulates editions.
Not a thing built; a loop running.

## The honest tension on "what next"
- **Phase 1 (Canon)** is unblocked and fully delegable to me — but **not
  perishable.** I can do it any time.
- **Phases 2–4 on the World Cup** are **perishable** — the WC 2026 window is open
  ~4 weeks, with the richest live data (FIFA EFI) and the Seleção playing *now*.

→ So the smart move isn't strictly sequential. **You** clear the perishable
blocker (a free API-Football key; later, the social accounts); **I**, in parallel
and unblocked, build the Canon *and* scaffold the live pipeline so it's ready the
moment the key lands. Then we stand up one real end-to-end output on a live
Seleção match — the loop, proven on the tournament while it's happening.

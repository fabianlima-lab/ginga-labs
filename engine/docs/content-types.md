# Content types

Derived from real reference accounts (the tactical-analysis corner of X):
@dzi_analysis, Tactx, Hosam Adel, and the Brazilian match-graphic accounts.
Every format is a *derivative* of the belief bank / match analysis.

## Tiers — by feasibility, not ambition

### Tier 1 — ship first (pure substance + we can render it, no rights issues)

| Format | Reference | Produced from |
|--------|-----------|---------------|
| **Belief thread** — *"what I believe X didn't do…"* | @dzi_analysis | belief revisions, published verbatim-ish |
| **Tactical concept thread** — bulleted breakdown (half-spaces, overloads, third-man) | Hosam Adel | a match's analysis tasks |
| **Pre-match post** — both formations + tactical notes | Rodrigo Coutinho | pre-match workflow + dossiers |
| **Best XI / team-of-the-round** — players on a pitch | Lucas Gabriel | post-round aggregation |
| **Formation / pitch graphic** | (all of the above) | **generated** — SVG pitch + positioned players (reuse the Prancheta tactical-board renderer) |

These need **zero broadcast footage** — no copyright exposure — and reuse
graphics work we've already proven (Remotion/SVG).

### Tier 2 — later (heavier + rights-sensitive)

| Format | Reference | Why deferred |
|--------|-----------|--------------|
| **Annotated video clip** — footage with drawings | Tactx, dzi_analysis | needs broadcast footage (copyright gray area) + video production |
| **Player report** with clips | Rodrigo Marques | same footage dependency |

## Brand voice

Portuguese-first (Brazilian football). Honest and falsifiable — the account's
edge is that every take is **tracked**: when a belief is rectified, that's a
post too ("I was wrong about X, here's why"). The track record *is* the brand.

## The authenticity loop

Because each post is backed by a pre-registered, tested belief, the content has
substance competitors can't fake. This is also what fixes the failure mode of
"AI content = filler": ours is lastreado — backed by real, tracked analysis.
